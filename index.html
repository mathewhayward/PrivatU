02 — WHAT WE INSTALL

Hardened Android. De-Googled. Verified boot.

GrapheneOS is an open-source Android build that removes Google services from the base system and hardens what remains — allocator, kernel, permissions, sensors.

Nothing we install is closed-source. Nothing phones home to us. You can audit every component we touch, and revert the device yourself if you want to.

Verified bootLocked bootloader, signed OS, attestation on demand
